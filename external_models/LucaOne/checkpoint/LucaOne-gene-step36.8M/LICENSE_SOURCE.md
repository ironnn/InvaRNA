# LucaOne checkpoint license source

The exact upstream Hugging Face model artifact
`LucaGroup/LucaOne-gene-step36.8M` declares `license: mit` in its model-card
metadata. At the time of this audit, that artifact did not publish a standalone
`LICENSE` file. The declaration is preserved in this file instead of inventing
an upstream copyright notice:

https://huggingface.co/LucaGroup/LucaOne-gene-step36.8M

The separately copied LucaOne source package is covered by the Apache-2.0
license retained at `baselines/models/lucaone_hf_pkg/LICENSE`.
