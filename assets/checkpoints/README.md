# Checkpoints

Model weights are deliberately not part of the figure-only publication asset
bundle. The checksum files in this directory are retained as provenance records;
the corresponding binaries are kept in the authors' private non-release archive.
The public Fig. 2--5 redraws use frozen numeric source tables and do not download
or load these checkpoints.

The manifest rows are historical availability records and cannot be verified until
the private weight archive is mounted. External-model download sources, versions,
licenses, and SHA-256 values are recorded separately under `external_models/`.
