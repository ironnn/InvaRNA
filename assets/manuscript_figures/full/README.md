# Current manuscript plotting data

This directory contains only the checked, current-paper tables that are read by
the publication plotting scripts. Historical Figure 3 packages, Figure 4 submission
workbooks, Fig. 5 raw workbooks, and RL trajectories are retained outside the release
bundle.

- `fig3_current_nm/`: canonical combined Figure 3 source tables.
- `fig5/`: F5C, F5D, and 20x F5E tables used by the standalone redraws.
